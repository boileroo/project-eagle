# Role Pill Colors

## What

Make the role pills more distinct from each other whilst also more consistent and cohesive as a feature.

Use multiple shades of the same colour (purple?) from guest (lightest) to commissioner (darkest)

## Done When

- Each role pill is a different color
- Each role pill is distinct from the others
- The roles pills together are consistent in appearance so they are more obviously part of the same feature.
