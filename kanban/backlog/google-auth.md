# Google Auth

## What

Implement 'continue with google'

## Context

Currently there is a placeholder Continue With Google button that does nothing. I have done none of the behind-the-scenes setup with Google cloud, nor the integration of Google with Supabase (our auth provider).

This ticket is to impelment the necessary code in-app and to provide step-by-step guidance on how to do the rest of the setup outwith.

## Done When

- A new user can sign up to the app using the Continue With Google button on the sign up page
- A returning user can sign into to the app using the Continue With Google button on the login page
