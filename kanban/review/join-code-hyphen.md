# Add hyphen to join code

## What

Auto-add a hyphen after the 5th character (i.e. after the 'golf word' part of the code) when joining a tournament using the join code.

## Context

- To join a tournament, users enter a 'code' provided by the commissioner.

- The code is always of the format [five letter golf word]-[random string]

- When entering the code by typing, the hyphen should automatically appear/disappear as the fifth character is enterred or deleted.

## Done When

- The hyphen automatically appears after the fifth character is entered
- The hyphen automatically disappears along with the fifth character when pressing backspace.
