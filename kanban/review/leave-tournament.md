# Leave Tournament

## What

Provide users with the ability to leave a tournament (or single round).

## Done When

- Users can leave a tournament that is in the draft stage but not later.

- Leaving should be done using the existing cross icon on the participants panel. It is currently disabled for non-commissioners; after this change the user's own cross will be enabled to allow them to leave.

- A new 'are you sure you want to leave' modal should be surfaced to let the user confirm before leaving.

- After leaving a User should be redirected back to the home dashboard

- Commissioners can only leave if there is a second commissioner. They are blocked if they are the only remaining commissioner.
